Hay — одна форма на всё

Hay — это особая форма глагола haber. Используется ОДНА форма для:

  • «Есть»: Hay un banco aquí. — Здесь есть банк.
  • «Имеется»: Hay tres habitaciones. — 3 комнаты.
  • «Есть ли?»: ¿Hay café? — Есть кофе?
  • «Нет (отрицание)»: No hay leche. — Нет молока.

💡 Hay не меняется по числу!

Hay un libro = есть книга.
Hay diez libros = есть 10 книг.
В обоих случаях — «hay». Не «han», не «hayan».

💡 Аналогия с английским

Hay = there is / there are. Одна форма для обоих.
«There is a book» = Hay un libro.
«There are 5 books» = Hay cinco libros.

3

Hay vs Está — главная таблица

HAY

  • Новый объект (un, una, unos, unas, числа)
  • Что есть в общем
  • «Существует» в пространстве
  • Hay un médico aquí.
  • Hay tres farmacias en la calle.
  • ¿Hay alguien? — Есть кто?

ESTÁ / ESTÁN

  • Известный объект (el, la, los, las)
  • Конкретное местоположение
  • Меняется по числу: está / están
  • El médico está en la consulta.
  • Las farmacias están abiertas.
  • ¿Dónde está María? — Где Мария?

Сравни:

— ¿Hay un baño cerca?
[Туалет есть рядом?] — Спрашиваем про НАЛИЧИЕ.
— Sí, hay uno. ¿Dónde está?
[Да, есть один. Где он?] — Сначала hay (есть), потом está (где конкретно).
— El baño está al fondo.
[Тот туалет в глубине.] — Конкретный, известный.
4

«Сколько есть?» — hay с числами

ВопросОтвет
¿Cuántas habitaciones hay?Hay tres habitaciones.
¿Cuánta gente hay?Hay mucha gente.
¿Hay alguna tienda abierta?Sí, hay una en la esquina.
¿Cuántos años hay entre vosotros?Hay 5 años de diferencia.

⚠️ Hay + неопределённое / Hay + число

«Есть стол» = Hay una mesa. (НЕ «Hay la mesa».)
«Есть 5 столов» = Hay cinco mesas.
С определённым артиклем (el/la) — используй ESTÁ: «El estol está aquí».
