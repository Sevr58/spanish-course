Por vs Para — главная пара

POR (через/из-за)PARA (для/чтобы)
Причина / мотивация
Lo hago por ti. — Делаю из-за/ради тебя.		Цель / получатель
Es un regalo para ti. — Подарок для тебя.
Время продолжительности
Por dos horas.		Дедлайн
Para mañana.
Маршрут / через место
Paso por el parque.		Направление
Voy para Madrid.
Обмен
Pago 5€ por el libro.		Мнение
Para mí, es importante.
Способ / средство
Por internet, por teléfono.		Профессия (для чего)
Estudio para médico.

💡 Простой тест

Если можно вставить «РАДИ / ИЗ-ЗА / ЧЕРЕЗ» → por.
Если «ДЛЯ / ЧТОБЫ / К» → para.

Примеры:

Trabajo por dinero.
[Работаю ради денег / из-за денег.]
Trabajo para mi familia.
[Работаю для семьи.]
El libro es para mí.
[Книга для меня.]
Voy a Madrid por trabajo.
[Еду в Мадрид из-за работы.]
