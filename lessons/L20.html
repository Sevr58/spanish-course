«Tener» — 20 выражений состояния

В испанском многие чувства/состояния = «иметь что-то». Это идиомы — запоминать целиком.

⚠️ Главная ошибка

НИКОГДА «soy/estoy hambre». Только «tengo hambre». В русском «Я ГОЛОДЕН» = в испанском «У меня есть голод» (Tengo hambre). Эта логика для 90% чувств.

4

Tener que + инфинитив = должен

Главная конструкция обязательства в испанском. Формула: Tener (форма) + que + infinitivo.

Tengo que estudiar.
[Должен учиться.]
Tienes que pagar.
[Ты должен заплатить.]
Tenemos que irnos.
[Нам надо уходить.]
¿Qué tengo que hacer?
[Что мне делать?]

💡 3 способа сказать «должен»

  • Tener que + inf. — конкретная обязанность для лица: «Tengo que ir».
  • Hay que + inf. — безличная обязанность: «Hay que estudiar» (нужно учиться вообще).
  • Deber + inf. — моральный долг (формальнее): «Debo ayudar» (должен помочь). См. L22.
