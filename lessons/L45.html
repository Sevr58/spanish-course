Imperativo — как образовать

Повелительное наклонение используется для команд, советов, просьб и инструкций. В испанском есть формы для «tú» (ты), «usted» (вы), «nosotros» (давайте мы) и «vosotros» (вы, множественное).

💡 Утвердительный Imperativo для tú — самая простая форма

Берёшь форму настоящего времени для «él/ella» (3-е лицо ед.ч.) — это и есть Imperativo для «tú»!
habla (hablar) — говори! (= él habla → habla!)
come (comer) — ешь! (= él come → come!)
vive (vivir) — живи! (= él vive → vive!)

❌ Отрицательный Imperativo — другие формы!

Отрицательный Imperativo образуется из Present Subjuntivo (не из настоящего времени!):
No hables — не говори (НЕ «no habla»!)
No comas — не ешь
No vengas — не приходи
Формула: No + subjuntivo presente (для tú: окончание -es для -AR, -as для -ER/-IR)

⚠️ Местоимения + Imperativo

С утвердительным Imperativo местоимения присоединяются сзади:
Dámelo — дай мне это! (da + me + lo)
Escúchame — слушай меня! (escucha + me)
Díselo — скажи ему это! (di + se + lo)
С отрицательным — местоимения перед глаголом: No me lo digas — не говори мне этого!

Тест 2 — Напиши Imperativo

✏️ Образуй форму повелительного

1. «poner» для tú = положи / поставь!
✅ pon — одна из 8 неправильных форм. Запомни: di, haz, ve, pon, sal, sé, ten, ven.
2. «leer» для usted = читайте (вежливо)!
✅ lea — для usted берём основу Present Subjuntivo. «Lea el documento» = Прочитайте документ.
3. Отрицательный Imperativo «не ешь» (tú, comer)
✅ No comas — отрицательный Imperativo от -ER для tú = -as. «No comas eso» = Не ешь это.
4. «escuchar» + me = слушай меня! (Imperativo tú с местоимением)
✅ Escúchame — местоимение присоединяется СЗАДИ в утвердительном Imperativo. Ударение сохраняется.
5. «ser» для tú = будь! (неправильная форма)
✅ sé — с акцентом! «Sé amable» = Будь вежливым. Без акцента «se» — это возвратное местоимение.

Говорение — Рецепт или инструкция

🎙 Базовый — Советы начинающему

Дай 7 советов человеку, который только начинает учить испанский язык. Используй только Imperativo.

Escucha español cada día. Habla con nativos. No tengas miedo de equivocarte. Lee textos sencillos...
Глаголы: escuchar, hablar, leer, escribir, repetir, practicar, ver, estudiar, no tener miedo.
🎙 Продвинутый — Рецепт

Объясни рецепт своего любимого блюда — шаг за шагом, используя Imperativo. Минимум 8 шагов.

Primero, coge... Luego, corta... Después, pon... Cocina... Añade... Mezcla... Al final, sirve...
Подойдёт любое блюдо: суп, салат, бутерброд, яичница. Главное — активно использовать повелительное!

Культурная заметка

🌍 Культурная заметка

Tortilla española — символ испанской кухни

Испанская тортилья (tortilla española) — это не мексиканская лепёшка! Это омлет с картошкой, и он считается одним из главных национальных блюд. В каждой испанской семье свой рецепт: с луком или без, толстая или тонкая, влажная внутри (jugosa) или полностью прожаренная (bien hecha). В барах тортилья продаётся весь день как часть pintxos или tapas. Есть даже ежегодные конкурсы «la mejor tortilla de España». Если хочешь интегрироваться в испанское общество — научись делать tortilla española. И тогда тебя точно примут за своего!
