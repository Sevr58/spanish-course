## Стандарт качества урока (ОБЯЗАТЕЛЬНО)

Каждый урок — самодостаточный HTML-файл. Он должен содержать:

### Структура (8–10 разделов):
1. **Навигация** — ссылки: ← Дашборд | Уровень/День | Следующий урок →
2. **Hero-блок** — фаза, название, подзаголовок, цели (4 карточки), прогресс-бар
3. **Теория** — объяснение грамматики простым языком + примеры + callout-блоки (tip/info/warning/success)
4. **Словарь** — 10–15 слов в таблице со значением, транскрипцией и примером предложения
5. **Тест 1** — 5–6 вопросов с множественным выбором (onclick-логика с правильным ответом)
6. **Тест 2** — 4–6 вопросов на заполнение пропусков (text-input с checkText)
7. **Диалоги** — 2–3 диалога (кнопка "показать перевод", читать вслух)
8. **Говорение** — speak-box с конкретными заданиями (не «расскажи о себе», а конкретный промпт)
9. **Культурная заметка** — интересный факт об испаноязычном мире
10. **Anki + Домашнее задание** — 6–8 карточек + задание до следующего урока
11. **Done-bar** — кнопка "Отметить пройденным" + навигация

### Правила содержания:

**Теория:**
- Объясняй КАК учитель с опытом, НЕ как словарь. Почему это правило, откуда оно, что изменится если забыть
- Используй сравнения с русским И с английским (ученик знает оба)
- Выдели самые частотные формы (топ-10 использования)
- Добавляй ЛОВУШКИ — типичные ошибки русскоговорящих студентов
- Минимум 2 callout-блока (tip/info) с дополнительным контекстом

**Словарь:**
- Слова группируй тематически
- Для каждого слова: испанский | произношение [транскрипция] | русский | пример предложения
- Отмечай когнаты с английским желтым цветом через span
- Включай 1–2 слова-«ловушки» (falsos amigos если применимо)

**Тесты:**
- Тест 1 (множественный выбор): ВСЕГДА правильный ответ = первый вариант в onclick (answerQuiz key 'a')
  НО порядок показа должен быть случайным — правильный ответ может быть 1-м, 2-м или 3-м визуально
  Для этого: в onclick пиши `answerQuiz(this,'qN','a')` где 'a' = правильный ответ key
  Неправильные варианты получают 'b' и 'c'
  Визуальный порядок можешь менять — главное что в onclick корректный key
- Тест 2 (текстовый): используй функцию checkText(inputId, 'ответ', 'fb-id')
- Минимум 5 вопросов в каждом тесте
- Объяснения к ответам — не просто "Правильно", а почему, какое правило

**Говорение (САМОЕ ВАЖНОЕ):**
- Конкретный сценарий, не абстрактный: "Позвони в отель и забронируй номер на 2 ночи"
- Дай шаблон ответа на испанском: «Quisiera reservar...»
- Дай переключаемый перевод
- 1–2 speak-box с разными уровнями сложности (базовый / продвинутый)
- В диалогах: всегда говори читателю прочитать ВСЛУХ, играя ОБЕ роли

**Аудирование:**
- Всегда указывай что слушать в этот день из Dreaming Spanish (уровень из data.js)
- Если урок про прошлое время — найди подходящий тип контента (истории, нарративы)
- Language Transfer: если у урока есть lt_episodes — конкретно укажи их номера

**Культурная заметка:**
- Реальный, интересный, специфический факт (не "Испания — красивая страна")
- Связанный с темой урока
- 3–5 предложений

### Визуальный стандарт (CSS):

Используй ТОЧНО те же CSS-классы и переменные что в L00.html:
```css
:root{--bg:#0d0f14; --bg2:#13161e; --bg3:#1c2030; --border:#2a2f42;

      --red:#e63946; --blue:#457b9d; --purple:#9d4edd; --r:10px}
```
Не изобретай новые классы. Скопируй весь блок `<style>` из L00.html.

### JavaScript:

Используй ТОЧНО ту же логику что в L00.html:
- `markDone()` — через localStorage
- `answerQuiz(el, qId, correctKey)` — тот же алгоритм
- `checkText(inputId, answer, fbId)` — тот же алгоритм
- `toggleTranslation(id)` — тот же
- Прогресс-бар через scroll

### Специфика для разных уровней:

**A0–A1 уроки (L02–L30):**
- Очень много русского объяснения
- Каждое испанское слово с транскрипцией
- Простые диалоги (2–4 реплики)
- Текущий уровень Dreaming Spanish: super_beginner
- Language Transfer: указывай эпизоды из data.js

**A1–A2 уроки (L31–L60):**
- Меньше транскрипций, больше контекста
- Диалоги длиннее (6–10 реплик)
- Добавляй сравнение с уже изученным
- DS: beginner

**A2–B1 уроки (L61–L100):**
- Объяснения краче, больше практики
- Аутентичный контент (короткий новостной отрывок, твит, объявление)
- Говорение: сложные сценарии
- DS: intermediate

**B1 уроки (L101–L121):**
- Минимум объяснений теории
- Максимум практики и самопроверки
- Аутентичные тексты на испанском без перевода
- DS: intermediate+

И в тексте урока упомяни: "Это расширение урока #N из курса Polyglot (Дмитрий Петров)".

## Важные правила

1. **Никогда не сокращай** — урок должен быть полным, не заготовкой
2. **Не используй placeholder-текст** типа "[здесь будет упражнение]"
3. **Проверяй правильность** испанских форм перед записью
4. **Тесты должны работать** — проверь что onclick-функции написаны правильно
5. **Файл должен открываться без сервера** — только localStorage, никаких fetch
6. **Минимальный размер** — 400 строк HTML. Идеально 600–800.
