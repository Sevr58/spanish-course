# Инструкции для агента: улучшение уроков испанского

## Задача

Ты — опытный преподаватель испанского языка, специалист по CEFR и практической лингвистике. За один запуск ты обрабатываешь РОВНО 2 урока:
- если файл урока отсутствует — пишешь его с нуля
- если файл существует — переписываешь/улучшаешь до нового стандарта

## Алгоритм за один запуск

1. Читай `data.js` — найди первые 2 урока, у которых `status !== "improved"`, по порядку (L01, L02, L03...)
2. Читай `lessons/L00.html` — скопируй CSS и JS оттуда ТОЧНО
3. Для каждого из 2 уроков:
   a. Если файл существует — прочитай его для контекста
   b. Напиши ПОЛНЫЙ улучшенный урок `lessons/LXX.html`
   c. Обнови `data.js` — измени `status` на `"improved"`
4. `git add -A && git commit -m "Improve lessons LXX and LYY: <titles>" && git push`

### Произношение — Web Speech API (ОБЯЗАТЕЛЬНО)

Добавь эту функцию в JS-блок каждого урока:

```javascript
function speak(text, lang) {
  const u = new SpeechSynthesisUtterance(text);
  u.lang = lang || 'es-ES';
  u.rate = 0.85;
  window.speechSynthesis.cancel();
  window.speechSynthesis.speak(u);
}
```

- Кнопка `<button onclick="speak('слово')" class="speak-btn">🔊</button>` у каждого слова в словаре
- Кнопка "Прослушать фразу" у каждой реплики диалога
- Кнопка "Воспроизвести диалог целиком" — setTimeout между репликами (2 сек паузы)

CSS для кнопки:
```css
.speak-btn{background:none;border:none;cursor:pointer;font-size:1rem;opacity:.7;transition:.2s}
.speak-btn:hover{opacity:1;transform:scale(1.2)}
```

### Анки-колода — встроенная + экспорт (ОБЯЗАТЕЛЬНО)

```javascript
const ANKI_DECK_LXX = [
  {
    front: "испанское слово/фраза",
    back: "Перевод: русское значение\n\nПример: ¡Hola! — Привет!\nЗаметка: используется неформально"
  },
  // ... минимум 15 карточек
];

function exportAnkiLXX() {
  const tsv = ANKI_DECK_LXX.map(c => c.front + '\t' + c.back.replace(/\n/g, '<br>')).join('\n');
  const blob = new Blob(['﻿' + tsv], {type: 'text/plain;charset=utf-8'});
  const a = document.createElement('a'); a.href = URL.createObjectURL(blob);
  a.download = 'LXX_spanish.txt'; a.click();
}
```

В разделе Анки покажи preview 5 карточек с CSS flip-анимацией и кнопку "Скачать колоду Anki (.txt)".

### Тесты

**Тест 1 (множественный выбор):**
- Правильный ответ ВСЕГДА ключ `'a'` в `answerQuiz(this,'qN','a')`
- Визуальный порядок вариантов можно менять — правильный может быть 1-м, 2-м или 3-м
- 6+ вопросов, объяснение к каждому ответу

**Тест 2 (заполнение пропусков):**
- `checkText(inputId, 'ответ', 'fb-id')`
- 5+ вопросов
- Подсказка "введите в нижнем регистре"
- **Функция `checkText` — копируй из `L00.html` ДОСЛОВНО**. Текущая версия:
  - игнорирует диакритику (á é í ó ú ñ ü) — `como` засчитывается как `cómo`
  - игнорирует ¿ ¡ ? ! . , ; :
  - допускает 1 опечатку для слов <6 символов и 2 опечатки для слов ≥6 символов (Левенштейн)
  - при опечатке/без ударений показывает правильное написание (поощряет, не штрафует)
- Правильный ответ в `'ответ'` пиши с полной диакритикой — `'¿Cómo estás?'`, не `'como estas'`
