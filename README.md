# Курс испанского A0 → B1

Самообучающий курс из 109 уроков (L00–L120). Каждый урок — статичный HTML без сервера, прогресс хранится в localStorage браузера.

## Как открыть

### Простой способ — двойной клик
Открой `index.html` или любой `lessons/LXX.html` двойным кликом. Работает: тексты, тесты, словарь с озвучкой 🔊, диалоги, Anki-карточки.

### С микрофоном — через локальный сервер
Микрофон 🎤 (проверка произношения) и AI-репетитор работают только через `http://localhost`, а **не** через `file://`.

**Запуск (Windows):**
1. Дважды кликни `run_local.bat`
2. Откроется браузер на `http://localhost:8000/index.html`
3. Чтобы остановить — закрой чёрное окно консоли

Требуется установленный Python (любая версия 3.x).

## Возможности

- 🔊 **Озвучка** — каждое слово в словаре, реплики в диалогах (Web Speech API синтез)
- 🎤 **Запись произношения** — Claude слушает твоё произношение и сравнивает с эталоном (требует Chrome/Edge + микрофон + localhost)
- 🧪 **Тесты** — множественный выбор + заполнение пропусков (с допуском опечаток и ударений)
- 📇 **Anki-колоды** — скачивание готовых `.apkg` файлов с озвучкой
- 🤖 **AI-репетитор** (L04–L08, дальше добавляется) — Claude Haiku 4.5 проверяет твои предложения и даёт шаблоны на старте. Нужен Anthropic API ключ.

## Уровни

- **L00–L30** (A0–A1) — основы: алфавит, артикли, простые глаголы
- **L31–L60** (A1–A2) — прошедшее, будущее, базовая речь
- **L61–L100** (A2–B1) — Subjuntivo, аутентичные тексты
- **L101–L120** (B1) — практика без подсказок
